<b>Job Application Tracking – Data Analysis with Power BI</b>

This project analyzes job application data using Power BI.
The goal was to clean and transform raw data into a structured format, then build an interactive dashboard to explore insights such as:

- Applications over time
 
- Reasons for rejection

- Candidate and vacancy distributions

<b> Data Preparation</b>

- Converted missing values (e.g., none → NA)

- Normalized and formatted columns

- Built a star schema with fact and dimension tables:

- Fact table: Applications

- Dimensions: Candidates, Vacancies, Rejection Reasons

<b> Dashboard Highlights</b>

The Power BI dashboard provides:

- Trends of applications

- Candidate statistics

- Rejection analysis

- Vacancy breakdown
